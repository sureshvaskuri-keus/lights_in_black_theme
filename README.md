# KEUS Luxury Lighting Catalogue

Static GitHub Pages project. Upload the complete folder contents without changing the structure.

## Main files

- `index.html` — dark catalogue and filters
- `light-details.html` — white product details page
- `category.html` — collection mockup page
- `inspiration.html` — editorial mockup page
- `assets/css/styles.css` — complete responsive design
- `assets/js/app.js` — CSV loading, filters, cards and details
- `data/*.csv` — existing product data
- `assets/images/` — existing product images and replaceable inspiration placeholders

The catalogue uses four columns on desktop and two on mobile. Mobile finish circles are reduced and the hero banner is intentionally compact.
